# 获取音频设备信息，设置默认音频设

**模块**: `sys:audioControl`

**官方文档**: https://getquicker.net/KC/Help/Doc/audiocontrol

## 概述

获取音频设备信息，设置默认音频设

## 输入参数

- `操作类型`
- `设备名称`

## 输出

- `设备列表`
- `当前设备`
