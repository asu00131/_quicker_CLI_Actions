# 获取当前或从文本、unix时间戳转换日期时

**模块**: `sys:getCurrentTime`

**官方文档**: https://getquicker.net/KC/Help/Doc/gettime

## 概述

获取当前或从文本、unix时间戳转换日期时

## 输入参数

- `时间格式`
- `输入时间戳`

## 输出

- `当前时间`
- `格式化时间`
