# 检查指定的应用程序是否已经启动

**模块**: `sys:checkProcessExists`

**官方文档**: https://getquicker.net/KC/Help/Doc/checkprocessexists

## 概述

检查指定的应用程序是否已经启动

## 输入参数

- `进程名或路径`

## 输出

- `是否运行`
- `进程信息`
