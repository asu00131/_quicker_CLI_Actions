# 获取Windows服务的状态、注册表项信

**模块**: `sys:winservice`

**官方文档**: https://getquicker.net/KC/Help/Doc/winservice

## 概述

获取Windows服务的状态、注册表项信

## 输入参数

- `操作类型`
- `服务名或注册表路径`

## 输出

- `服务状态`
- `注册表值`
