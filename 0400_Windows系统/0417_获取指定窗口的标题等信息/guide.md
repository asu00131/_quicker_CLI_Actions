# 获取指定窗口的标题等信息

**模块**: `sys:getWindowTitle`

**官方文档**: https://getquicker.net/KC/Help/Doc/getwindowtitle

## 概述

获取指定窗口的标题等信息

## 输入参数

- `窗口句柄或标题`

## 输出

- `窗口标题`
- `进程名`
- `类名`
